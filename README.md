# Homebrew tap

```sh
brew install --cask diiad/tap/clementine   # Clémentine, the menu-bar app
brew install diiad/tap/clementine-cli      # the `clementine` command only
```

[Clémentine](https://github.com/diiad/clementine-mac): drag a file, hold a key, drop it on the wheel. An open-source, offline file converter for macOS.
